============================================================
  АНАЛІЗ БРОНЬЮВАННЯ — ЗП
============================================================

ПЕРШИЙ ЗАПУСК НА НОВОМУ КОМП'ЮТЕРІ:
-----------------------------------
1. Двічі клікніть на "install.bat"
   - Він встановить Python (якщо не встановлений)
   - Встановить всі залежності
   - Створить ярлик на робочому столі

2. Якщо встановлювався Python — закрийте всі вікна
   і запустіть install.bat ще раз (для оновлення PATH).


ЗАПУСК ПРОГРАМИ:
----------------
- Двічі клікніть на "run.bat"
- Або через ярлик "Аналіз бронювання" на робочому столі


ФАЙЛИ:
------
  bron_analysis_all.py  — основна програма
  bron_settings.json    — налаштування (мін. ЗП, коефіцієнти, ліміт)
  requirements.txt      — список залежностей Python
  install.bat           — встановлення (запустити один раз)
  run.bat               — запуск програми


ВИМОГИ:
-------
  - Windows 10/11
  - Python 3.10+ (встановлюється автоматично)
  - openpyxl (встановлюється автоматично)
  - tkinter (входить до складу Python)


РОЗВ'ЯЗАННЯ ПРОБЛЕМ:
--------------------
- "Python не знайдено" → закрийте і знову запустіть install.bat
- "Не вдалося встановити Python через winget" → install.bat
  спробує завантажити Python з python.org автоматично
- Якщо нічого не виходить — встановіть Python вручну з
  https://www.python.org/downloads/ (обов'язково ✓ "Add to PATH")
  і запустіть install.bat ще раз
